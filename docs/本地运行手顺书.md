# 源码与浏览器运行手顺书

版本：0.4.0。日常使用优先参考 [Mac 桌面版手顺书](桌面版使用与迁移手顺书.md)。本文件适用于在源码目录启动浏览器后台；其配置和数据位置与桌面 App 不同。

## 1. 演示启动

在项目根目录运行：

```bash
./start.sh --demo
```

脚本在缺少 `.venv` 时自动创建环境并安装锁定依赖。浏览器打开 `http://127.0.0.1:8091/#add`；未配置管理密码时，终端显示本次随机演示密码，用户名默认为 `admin`。演示数据只写入本机 `instance/onboarding/demo/`。

Mac 也可以双击 `start.command`。退出时在终端按 Ctrl+C，关闭浏览器不会结束后台。端口被占用时可用 `./start.sh --demo --port 8092`。

## 2. 配置真实连接

仅在 `local_settings.json` 不存在时复制模板，避免覆盖已有设置：

```bash
cp -n local_settings.example.json local_settings.json
chmod 600 local_settings.json
./start.sh --configure
```

编辑本机 JSON，把示例路径与 SSH 地址替换为自己的配置。环境变量优先于 JSON；`.env.example` 不会自动加载。

| 字段 | 用途 |
|---|---|
| `DATA_MODE` | `demo` 或 `oracle` |
| `ADMIN_PASSWORD_HASH` / `SESSION_SECRET` | 通过配置命令生成管理密码哈希与会话密钥 |
| `ORACLE_CREDENTIALS_FILE` | 本机两行文本：数据库账号、密码 |
| `WRITE_ORACLE_CREDENTIALS_FILE` | 写连接的账号密码文件；可与读账号分开 |
| `ORACLE_DSN` | Wallet 中的连接别名 |
| `ORACLE_CONFIG_DIR` / `ORACLE_WALLET_LOCATION` | Wallet 目录 |
| `ORACLE_WALLET_PASSWORD` | Thin 模式加密 Wallet 需要的密码 |
| `ORACLE_CLIENT_LIB_DIR` | 可选 Thick 客户端目录；包含自动登录 Wallet 时可免 Wallet 密码 |
| `SHOWROOM_SSH_HOST` / `SHOWROOM_SSH_USER` | 3C SSH 地址或本机 SSH 别名、用户名 |
| `SHOWROOM_SSH_IDENTITY_FILE` | 可选显式指定的 3C 私钥路径 |
| `SHOWROOM_SSH_KNOWN_HOSTS` | 可选显式指定的可信主机文件，三台日志连接共用 |
| `SHOWROOM_INDEX_DIR` | 3C 索引目录，通常为 `/home/ubuntu/showroom/index` |
| `SHOWROOM_REMOTE_BACKUP_DIR` | 3C 索引备份目录 |
| `LOG_1C_HOST` / `LOG_1C_USER` / `LOG_1C_IDENTITY_FILE` | 1C 日志 SSH 连接 |
| `LOG_4C_HOST` / `LOG_4C_USER` / `LOG_4C_IDENTITY_FILE` | 4C 日志 SSH 连接 |
| `ALLOW_MEMBER_CREATE` | `0` 关闭、`1` 开启真实成员添加和修改 |
| `MEMBER_STATE_DIR` | 本机操作记录和演示索引目录，demo 与 oracle 分开 |

浏览器真实模式需要管理页面密码；桌面 App 使用本机会话，无需该密码。钱包目录名不是密码。不要把数据库密码、私钥或完整配置放进 Git。

## 3. 检查与启动

```bash
./start.sh --check
./start.sh --oracle
```

`--check` 检查 Oracle、3C SSH、索引和权限，仅读取，不创建成员或更新索引。1C／4C 日志连接在日志工作台中分别验证。SSH 始终严格检查主机指纹；指纹变化应先核实服务器身份。

Oracle 页面使用现有 `ADMIN` 下的成员、组合、直播状态、上传配置等表，保留的查询接口还使用实例及分配历史、`V_INSTANCE_LOAD` 等对象。此项目不创建表或执行 DDL。开启写入前需要相应的成员、上传配置及标签读写权限，并确认现有录制链路的加载流程。

真实模式查询失败不会自动替换成演示数据。只有 `ALLOW_MEMBER_CREATE=1` 才开放写入；切换配置后重新启动后台。

## 4. 成员与日志操作

当前页面包含添加成员、成员目录、日志工作台。浏览器方式没有桌面原生的设置／迁移入口，连接配置需编辑本机 JSON。

添加、修改字段、模板与恢复流程详见 [桌面版手顺书第 6 节](桌面版使用与迁移手顺书.md)。数据库 Team 与 jdex 日文队伍是独立字段；索引文件名需保留服务器上的大小写。保存配置不会重启监控或录制器，生效时间由现有云端程序决定。

日志仅读取 `/home/ubuntu/logs`，每次最多 256 KB、1,000 行，不读取压缩文件、不推断录制状态。

## 5. 故障、备份与更新

- 查询失败：检查网络、Wallet、DSN 和账号权限。
- 保存中断：恢复连接后重试原操作，不重复添加或删除操作记录。
- 索引冲突：核对其他管理端或手工修改，避免覆盖。
- 保存完成但未录制：核对 1C 成员刷新、3C 索引加载及分配状态。
- 本地操作记录在 `MEMBER_STATE_DIR`；3C 索引备份在配置的远端备份目录。它们不等于生产数据库备份。
- 更新源码时保留 `.venv`、`local_settings.json` 和 `instance/`；无需同步整个管理项目到三台服务器。

备份本机配置与 SQLite 前先停止浏览器后台。使用一台管理电脑操作，避免并发修改同一成员。不要用旧索引整文件覆盖当前索引，旧文件可能缺少后续新增成员。
